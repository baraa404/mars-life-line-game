# Object references for 3D modeling

All reference images and the model are stored directly in this folder. There are no phase or archive subfolders.

Use the image named after the catalog object. Files ending in `-alternative` preserve earlier or rejected versions; they are not the approved modeling reference. Files ending in `-provenance.json` retain generation prompts and source details. Catalog dimensions and named nodes remain the modeling requirements.
