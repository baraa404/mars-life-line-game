# Bundled game fonts

Nunito — body text, 200–1000 weight variable font. Baloo 2 — headings, 400–800 weight variable font.
Original upstream files from Google Fonts, downloaded 2026-11-13. See manifest.json for exact source URLs and SHA-256 hashes.
Both are distributed under SIL Open Font License 1.1; original full licence/copyright notices are Nunito-OFL.txt and Baloo2-OFL.txt.
Local CSS font faces use font-display: swap and system fallbacks. No external runtime fetch is required.
