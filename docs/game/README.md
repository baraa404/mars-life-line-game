# Mars Life Line — Game documentation

Status: Phase 3 hab, player interactions, Station View, PEBBLE and HUD are integrated. See [Phase 3 verification](phase-3-verification.md).
The base, landing site and northern repair/shelter route stand on the terrain.
Simulation-driven environment and materials are active. [Touchdown](phase-4-touchdown.md)
is playable from the title through the first wake-up report.
See [Phase 2 verification](phase-2-verification.md).
See [Phase 1 verification](phase-1-verification.md).

A future solo Mars mission for ages 7–12: keep Life Line Station alive with
PEBBLE while balancing power, air and water. Major decisions show benefits,
costs and later consequences. Views are first person, isometric Station View
and 2D panels, sharing one deterministic state and one balanced setting.

Start with [the plain-language plan](../../game-design/00-START-HERE.md), then
[vision and world](../../game-design/01-vision-story-world.md),
[missions](../../game-design/02-missions-events-campaign.md),
[systems and production](../../game-design/03-systems-ux-tech-production.md),
[asset catalog](../../game-design/04-asset-catalog.md) and
[implementation checklist](../../game-design/05-implementation-checklist.md).

The MVP route is M0 Touchdown → M1 Night Shift → M10 The Day the Sun Roared,
with a Mission Log bridge. The full campaign continues to Sol 60.
